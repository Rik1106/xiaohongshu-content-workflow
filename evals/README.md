# 行为验证
tasks.json 中是合成的小红书工作任务，用于验证本包行为；不是账号历史数据或增长案例。

对评估 Agent 只给目标 Skill、任务输入与必要材料。不要先给评分答案。若要比较基础提示与本包，用相同模型/材料/工具条件，在独立上下文运行并保留原始结果。未配置多 Agent 的宿主可分会话人工执行。

观察：任务是否完成、有没有遗漏/虚构条件、认可稿是否被保护、是否正确处理指标与评论、偏好范围是否正确、是否真实写入获准位置。
不以字段齐全、模型自评分数、前置格式合格判断有效。测试路径必须是隔离目录，不发送或发布任何内容。

tasks.json 是输入；rubric.json 是执行后审阅标准。docs/VALIDATION.md 记录实际覆盖情况，未测不得写通过。
